# OpenMS_logo

Repository for creating OpenMS logos. Each letter and each bar of the logo is
generated by its own Python function, so you can build sublogos from any subset.

```bash
pip install -r requirements.txt
python -m openms_logo full                 # build/full.svg + build/full-white.svg
python -m openms_logo --list               # presets and element names
python -m openms_logo --elements M,S,bar_11,bar_12,bar_13,bar_14,bar_15,bar_16 --name ms-mark
```

```python
from openms_logo import compose, elements as E
svg = compose(E.bars_under_O() + [E.letter_O()], theme="white")
```
